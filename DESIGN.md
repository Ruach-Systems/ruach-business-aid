# Business Aid by RUACH visual system

The user-approved parent visual language is RUACH. The integrated product emblem,
**C / Balanced Record**, is agent-selected and remains pending owner review.
The parent Living Breath mark is immutable; no parent catalog files are changed.

## Application surfaces

Operate mode: business users record sales, stock and expenses, inspect reports
and manage account/workspace access. Preserve the established responsive shell,
cards, forms, navigation, focus treatments, state semantics and information order.
Use the existing light interface with Obsidian navigation; no theme-switching
feature is introduced.

## Tokens and typography

Crimson `#B21F32` carries primary actions and the product emblem. Obsidian
`#141821` carries navigation and headings. Royal Aubergine `#321C3B` carries
selected/information states, with `#EFE8F1` for their light surfaces.
Ivory `#F7F3ED` is the application background, White the card surface,
Slate `#696270` secondary text and `#D6CDD2` neutral borders.
Success uses `#2E6B57`; warning amber remains separate from the brand palette.

Use bundled Inter for interface text. Manrope 800 is the outlined product
wordmark; Inter 400 is the outlined `by RUACH` endorsement. Font-based icon
ligatures are not introduced. Existing CSS variable names remain private aliases
to minimize unrelated changes; their values now implement RUACH.

## Assets and exceptions

`branding/balanced-record-master.svg` is the geometry source. The comparison
board retains A/B/C alternatives for owner review. `scripts/build-brand.ps1`
generates consistent SVG/PNG/ICO assets and hashed application URLs.
The generic design detector's Inter warnings are intentional false positives:
Inter is explicitly required by the approved RUACH guide. Existing cards,
eyebrows and responsive structure are preserved by the user's no-layout-change
requirement, not introduced as new design choices.
